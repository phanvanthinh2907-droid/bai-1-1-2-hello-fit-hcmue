## Kiến thức sử dụng
- Cấu trúc trang HTML: DOCTYPE, html, head, meta charset, title, body
- Tiêu đề h1, đoạn văn p, xuống dòng br
- In đậm b, in nghiêng i
- Siêu liên kết a href, mở tab mới target="_blank"

## Cách chạy
Mở thư mục bằng VS Code, chuột phải `index.html` → **Open with Live Server**.
